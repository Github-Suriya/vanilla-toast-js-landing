# Vanilla Toast JS Landing

Landing page for [`vanilla-toast-js`](https://www.npmjs.com/package/vanilla-toast-js), a lightweight framework-independent toast notification library for Vanilla JavaScript.

## Run Locally

Prerequisite: Node.js

```bash
npm install
npm run dev
```

Package links:

- NPM: https://www.npmjs.com/package/vanilla-toast-js
- GitHub: https://github.com/Github-Suriya/vanilla-toast-js
